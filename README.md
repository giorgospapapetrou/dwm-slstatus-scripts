# dwm slstatus Scripts

A small collection of Bash scripts used in my Arch Linux + dwm workflow for displaying system information in a custom slstatus bar.

## Scripts

- `battery-monitor` - battery monitoring script
- `battery-status` - displays battery status
- `volume-status` - displays volume status
- `wifi-status` - displays Wi-Fi/network status
- `keyboard-layout` - displays keyboard language


## Usage

Make the scripts executable:

    chmod +x battery-monitor battery-status volume-status wifi-status

Run a script:

    ./battery-status

## Environment

- Arch Linux
- dwm
- slstatus
- Bash
